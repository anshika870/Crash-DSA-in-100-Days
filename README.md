## 💻 How I Approach Each Problem

Every problem gets the same treatment:

1. **Understand the problem** — Read carefully and identify the constraints.
2. **Give it a real attempt** — Try solving it independently before looking for hints.
3. **Find the pattern** — Understand why the approach works, not just how.
4. **Write the solution** — Implement it in Java and test edge cases.
5. **Optimize** — Analyze time and space complexity.
6. **Revisit** — Solve it again without help after a couple of days.

Because getting the right answer is good, but understanding why it's right is even better.
